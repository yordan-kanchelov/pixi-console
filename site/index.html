Your browser console,
inside the canvas.

pixi-console captures console.log, warnings and uncaught errors and draws them on top of your scene. It's built for debugging on phones, tablets and TVs where you can't open devtools.

npm install pixi-console

Options

textRenderer

Captures everything

It captures log, info, debug, warn and error, plus uncaught errors, unhandled promise rejections and console.clear(). Your devtools keep working as usual.

Reads like devtools

It supports printf-style %s %d %o substitutions. Objects, Maps and Sets are pretty-printed, circular references are handled, errors show their stack, and repeated messages collapse into one line.

Virtualized & fast

Only the visible lines exist as display objects, drawn with BitmapText from a single glyph atlas. Layout happens at most once per frame, so a flood of logs costs almost nothing.

Touch friendly

Scroll with the wheel or by dragging. The toolbar lets you filter by level, clear, and close the console. It opens itself when an error happens.

Fits any screen

autoResize follows your renderer across window resizes and orientation changes. Put the console anywhere with a layout function.

Tiny & typed

Zero runtime dependencies besides pixi.js. Ships ESM, CommonJS and a <script> build with full TypeScript types.

Quick start

import { Application } from "pixi.js";
import { PixiConsole } from "pixi-console";

const app = new Application();
await app.init({ resizeTo: window });
document.body.appendChild(app.canvas);

const devConsole = new PixiConsole({
    autoResize: { renderer: app.renderer },
});
app.stage.addChild(devConsole);

console.log("Hello from the canvas!");

Or with a script tag

<script src="https://cdn.jsdelivr.net/npm/pixi.js@8/dist/pixi.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/pixi-console@5"></script>
<script type="module">
    const app = new PIXI.Application();
    await app.init({ resizeTo: window });
    document.body.appendChild(app.canvas);

    const devConsole = new PixiConsole.PixiConsole({ visible: true });
    app.stage.addChild(devConsole);
</script>
